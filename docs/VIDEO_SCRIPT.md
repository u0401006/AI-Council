# AI Council Promo Video Script

> Duration: ~48 seconds (6 segments × 8 seconds)
> Style: Casual, upbeat, conversational English
> Target: Chrome Web Store promotional video

---

## Persona/Character Setup

**Character**: "The Council Curator"
- **Vibe**: Friendly tech enthusiast, like a helpful AI-savvy friend
- **Tone**: Casual, upbeat, confident but not salesy
- **Voice**: Fast-paced but clear, energetic, conversational
- **Visual style**: Modern, clean UI animations with the extension in action

---

## Script Segments

### Segment 1: Self Introduction (0:00 - 0:08)

**Voiceover:**
> "Hey! Ever asked ChatGPT something... and wondered if it's actually right?
> Yeah, me too. That's why I built AI Council."

**Visual**: Person typing into ChatGPT, then showing a confused emoji/reaction

**Text Overlay**: "IS THIS RIGHT?"

---

### Segment 2: Extension Introduction (0:08 - 0:16)

**Voiceover:**
> "AI Council asks GPT, Claude, Gemini, AND Grok — all at once.
> Four AIs. One question. Real answers."

**Visual**: Split screen showing 4 AI models responding simultaneously with streaming text

**Text Overlay**: "ONE QUESTION" → "FOUR AIs"

---

### Segment 3: Key Feature - Peer Review (0:16 - 0:24)

**Voiceover:**
> "Here's the magic — they review each other. Anonymously.
> No bias. Just rankings. The best answer wins."

**Visual**: Show the peer review UI with rankings (1st, 2nd, 3rd) appearing, highlight "Anonymous Review" badge

**Text Overlay**: "PEER REVIEW" → "NO BIAS"

---

### Segment 4: Key Feature - Skills (0:24 - 0:32)

**Voiceover:**
> "Need research? Fact-checking? Code help?
> Nine Skills auto-match your question. Zero setup."

**Visual**: Show skill icons appearing and auto-selecting based on question type (researcher, fact-checker, technical, creative, etc.)

**Text Overlay**: "9 SKILLS" → "AUTO-MATCH"

---

### Segment 5: Key Feature - Structured Image Generation (0:32 - 0:40)

**Voiceover:**
> "Want images? It keeps your style consistent — across TEN pictures.
> Same characters. Same vibe. Every time."

**Visual**: Show multi-image generation with consistent style, character consistency demo (e.g., family illustration series)

**Text Overlay**: "CONSISTENT STYLE" → "EVERY TIME"

---

### Segment 6: Call to Action (0:40 - 0:48)

**Voiceover:**
> "Free. Open source. Your API keys, your data.
> Grab it on Chrome Web Store. Link in bio!"

**Visual**: Chrome Store badge, QR code, animated "Install Now" button with confetti

**Text Overlay**: "FREE & OPEN SOURCE" → "INSTALL NOW"

---

## Production Notes

### Key Messaging Points

| Feature | Hook | Value Prop |
|---------|------|-----------|
| Multi-model query | "Four brains > one brain" | Diverse perspectives |
| Peer review | "AIs fact-check each other" | Reduced hallucination |
| Skills | "Auto-pilot mode" | Zero configuration |
| Image generation | "Style consistency magic" | Professional series output |

### Visual Rhythm

- **Seconds 1-16**: Hook + Context (problem → solution)
- **Seconds 17-40**: Features showcase (3 features, rapid-fire)
- **Seconds 41-48**: CTA (action-oriented close)

### Suggested Background Music

- Lo-fi beats or upbeat electronic (no lyrics)
- BPM: 100-120 for energetic pacing
- Suggested: Epidemic Sound, Artlist, or YouTube Audio Library

### Text Overlays Summary

2. "ONE QUESTION" / "FOUR AIs"
3. "PEER REVIEW" / "NO BIAS"
4. "9 SKILLS" / "AUTO-MATCH"
5. "CONSISTENT STYLE" / "EVERY TIME"
6. "FREE & OPEN SOURCE" / "INSTALL NOW"
