---

## Recommended Tools

### Video Editing
- **Free**: DaVinci Resolve, CapCut, Canva Video
- **Paid**: Final Cut Pro, Adobe Premiere Pro

### Motion Graphics
- **Free**: Canva, CapCut templates
- **Paid**: After Effects, Motion

### Audio
- **TTS**: Use the `tts-voiceover.html` helper page
- **Music**: Epidemic Sound, Artlist, YouTube Audio Library
- **Recording**: OBS, QuickTime (capture TTS playback)

---

## Export Settings

### For YouTube/Social Media
```
Format: MP4
Codec: H.264
Resolution: 1920x1080
Frame Rate: 30fps
Bitrate: 10-15 Mbps
Audio: AAC 320kbps
```

### For Chrome Web Store
```
Format: MP4 or WebM
Max Duration: 30-60 seconds
Max Size: 10MB
Resolution: 1280x800 recommended
```
